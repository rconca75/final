# Final Project: Group Onion

This repository has the entirety of our project with relevant code, data, and styling files uploaded.

## Site Creation Files

**index.html:** The main HTML file that creates our site. Links to the JS and CSS files to render visualizations and styling.

**d3vis.js:** The JS file with all of the work to create our visualizations/interactivity.

**style.css:** The CSS file that standardizes the styling for the webpage.

## Data Files

**All contained in the `data` folder**

**onion_data.csv:** The main dataset with data regarding specific quote entries.

**photos.csv:** The CSV file with photo IDs and links to render the photos.

## Projectbook Files

**projectbook.md:** The initial projectbook file using Markdown for easy formatting and image insertation.

**projectbook.pdf:** The final product of our projectbook exported from the original Markdown file.

## Other Files

**img folder:** A folder containing all the screenshots contained in the projectbook documenting the continual development of our project.

**gh-pages branch:** A branch to update the gh-pages site without interfering with the main branch.

**styling branch:** A branch for styling updates to styling without interfering with the main branch (not active after first few commits, mainly just for meetings where more than one person were working at a time).
